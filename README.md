# Chips Add & Delete App

A simple React application that allows users to dynamically add and remove chips (tags) from a list.

## 🧩 Features

- Add new chips by typing and hitting enter
- Delete individual chips with a single click
- Clean, responsive UI using Tailwind CSS

## 🛠️ Tech Stack

- JavaScript (ES6+)
